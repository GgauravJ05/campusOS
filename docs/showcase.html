Every syllabus topic, where it lives in the code.

CampusOS is the campus platform where a club requests a venue, faculty approve it, students reserve seats, and every decision is recorded. This page shows which second-year topic each part applies, the exact file it is written in, and the test that proves it works.

Our rule: we used a topic only where the project had a real job for it. Anything else, we left out and say so at the end of this page.

Fundamentals of AI

Not used, by design: the department asked for fundamentals. "Recommendations" is a weighted score ranked with a heap, not a model.

Structures with no job here

No stack, BST or round-robin scheduler. Nothing in a booking system needs them, and a demo file would not be an application of the course.
